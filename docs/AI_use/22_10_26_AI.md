### What the file is for

`src/h2_bottleneck/props.py` is the **single place** where gas properties are calculated. Every other model calls it. If the property method changes, it changes in one auditable place.

### The code

```python
"""Thermophysical properties of pure gases via CoolProp.

All inputs and outputs are SI: pressure in Pa, temperature in K.
CoolProp uses reference-quality equations of state:
  Hydrogen - Leachman et al. (2009); Methane - Setzmann and Wagner (1991),
the same ones used by Scafidi et al. (2023).
"""
from CoolProp.CoolProp import PropsSI

# Standard reference conditions for "standard cubic metres" (Sm3).
# 15 degC and 1 atm, the convention used in UK gas metering.
P_SC = 101_325.0   # Pa
T_SC = 288.15      # K

GASES = ("Hydrogen", "Methane")


def _check(gas):
    if gas not in GASES:
        raise ValueError(f"gas must be one of {GASES}, got {gas!r}")


def rho(p, T, gas):
    """Density (kg/m3) at pressure p (Pa) and temperature T (K)."""
    _check(gas)
    return PropsSI("D", "P", p, "T", T, gas)


def mu(p, T, gas):
    """Dynamic viscosity (Pa.s) at p (Pa), T (K)."""
    _check(gas)
    return PropsSI("V", "P", p, "T", T, gas)


def Z(p, T, gas):
    """Compressibility factor (-): Z = p / (rho * R_specific * T)."""
    _check(gas)
    return PropsSI("Z", "P", p, "T", T, gas)


def rho_sc(gas):
    """Density at standard conditions (kg/Sm3)."""
    return rho(P_SC, T_SC, gas)


def q_sc_to_mdot(q_sc, gas):
    """Convert standard volumetric flow (Sm3/s) to mass flow (kg/s)."""
    return q_sc * rho_sc(gas)
```

### Line by line

**The docstring at the top.** Anyone auditing the code reads this first. It states the units and **which equations of state are used**, with references. Because they're the same ones Scafidi et al. use, any difference between your results and theirs can't come from the gas properties.

**`from CoolProp.CoolProp import PropsSI`.** CoolProp is a free, reference-quality property library. `PropsSI` always follows this pattern:

```
PropsSI(output, input1_name, input1_value, input2_name, input2_value, fluid)
```

For example, `PropsSI("D", "P", 100e5, "T", 300, "Hydrogen")` means "the **D**ensity at **P** = 100 bar and **T** = 300 K, for hydrogen". Two independent properties fix the state of a pure gas. The output codes used here are `D` (density), `V` (viscosity) and `Z` (compressibility). Everything is in SI units, which is why the whole project uses SI.

**`P_SC` and `T_SC`, standard conditions.** Gas flows are usually quoted as standard volumes, for example "million m³/d" or "MMSCF/d". These are the volumes the gas would occupy at a reference pressure and temperature. Conventions differ (0 °C, 15 °C, 60 °F), and the differences can reach about 5%. Defining them once means the choice is visible and consistent everywhere. **Check which convention each source uses before comparing numbers.** Scafidi uses field units at 60 °F.

**`GASES` and `_check`, a guard.** This limits the code to two exact names, so a typo fails loudly rather than silently running the wrong gas. The leading underscore means "internal helper".

**`rho`, `mu` and `Z`, readable wrappers.** Elsewhere you'll write `props.rho(p, T, "Hydrogen")` instead of a cryptic `PropsSI` call, and each docstring states its units.

**Why Z matters.** An ideal gas has Z = 1. At reservoir conditions, hydrogen has Z above 1, so it's harder to compress than an ideal gas, while methane has Z below 1. This is part of why hydrogen stores less energy per cubic metre than the heating values alone suggest. Lüddeke et al. find compressibility is the property with the largest influence on withdrawal behaviour.

**`rho_sc`, density at standard conditions.** About 0.085 kg/Sm³ for hydrogen and 0.68 kg/Sm³ for methane. It turns standard volumes into mass.

**`q_sc_to_mdot`.** Flow equations use **mass flow**, because mass is conserved along a pipe while volume isn't: the gas expands as pressure falls. Published rates are in standard volumes, so this converts between the two.
